Checking the Supabase connection…

Finish Supabase setup
  1. Create a Supabase project and run supabase/schema.sql in its SQL Editor.
  2. For Vercel, verify the project URL and a publishable/anon key in Environment Variables, then redeploy. Locally, put SUPABASE_URL and SUPABASE_PUBLISHABLE_KEY in .env and restart.
  3. Add this site's URL to Supabase Auth's allowed redirect URLs, then create your account here.

Never put a service-role or secret key in this app.
