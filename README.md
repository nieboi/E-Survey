# E-Survey

A responsive household survey UI concept built as a static front-end prototype.

## Overview
This project presents a glassmorphism-inspired interface for a Janaseva-style eSurvey experience. It includes screens for:
- dashboard overview
- household profile entry
- family tree and member listing
- individual member details
- land and asset information
- review and summary

## Files
- `index.html` — page structure and survey screens
- `styles.css` — styling and responsive layout
- `script.js` — demo interactions and navigation logic
- `README.md` — project overview

## Run locally
Open `index.html` in a modern browser.

## Notes
This is a design prototype only. It does not save or submit data to any government or production system.
